# P4 三组效果实验的逐单元公开摘要

[results.json](results.json) 由操作者保留的正式只读审计投影生成，包含 21 个单元的状态、耗时、报告费用、失败原因，以及报告、收据、评分文件和前后快照的哈希。`sourceAuditSha256` 绑定的是原审计文件本身；完整报告、原生事件、补丁和收据仍保存在操作者私有目录，这里只能核对汇总是否与单元一致，不能代替证据验读。

**测试对象不是已发布版本。** 实验候选为 `f92905541710…`（6 条规则、22 个分支，覆盖 scoped read 与 Dream UPDATE），已发布的是其后继 `c7fb3c895b2d…`（2 条规则，只覆盖 Dream UPDATE 多余位置参数）。两者范围不同，本实验结论不能直接用于 c7。
